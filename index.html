Summary

I test AI systems to find out if they actually work. Before I run anything, I decide what counts as a pass and build a broken version that should fail, so I know the test can tell the difference. When something doesn't hold up, that goes on the record too. I use AI coding tools to build what I test, and my part is figuring out whether it's any good.

Hearsay: provenance-aware beliefs for game NPCs

2026 · v1.0 · private

NPCs believe what they hear based on who said it, where the claim started, and whether the source held up when checked. Copies of one source count once; contested subjects make NPCs verify instead of act.

  • Every feature shipped with a pre-registered test and a control that must fail.
  • Core promises verified on 300 randomly generated worlds.
  • Decision time cut from 1.4 s to about 35 ms with identical answers (982 of 982).
  • Runs in Unreal Engine 5.8: 1,914 engine calls, 0 failed, 29.7 ms worst frame.

Code available to studios on request. Next: a playable tavern slice.
