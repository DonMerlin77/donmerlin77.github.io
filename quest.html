Main Quest

Hearsay: NPCs that remember who told them what

IN PROGRESS

Most game characters know everything or nothing. In Hearsay, a villager believes a rumor based on who said it, where it started, and whether that person held up when checked. Ten people repeating one source count as one voice. When a subject is contested, the NPC goes to look for itself instead of acting on a guess. Personalities, moods and relationships let a whole town disagree in believable ways.

  • Build the belief layer, with a test written in advance and a control built to fail for every feature
  • Prove the core promises on 300 randomly generated worlds, not hand-picked demos
  • Make it fast without changing a single answer: 1.4 s to ~35 ms per decision, 982 of 982 identical
  • Run it inside Unreal Engine 5.8: 1,914 engine calls, 0 failed, worst frame 29.7 ms
  • A playable tavern where the regulars remember how you treat them
  • NPCs that speak in their own voices, from what they actually believe

Code of the Order

how every quest is run
  1. Write the claim so it can be wrong. A specific prediction, not "it works".
  2. Set the kill line before running. The pass/fail bar is committed before any result exists.
  3. Build a control that must fail. If the test can't catch a broken version, the test is blind.
  4. Let the measurement decide. Not my opinion, and never a model grading itself.
  5. Keep the failures. Negative results go in the same ledger as the wins.
